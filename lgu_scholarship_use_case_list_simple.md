# Simple General Use Case Diagram

## System
Automated Scholarship Records Management System

## Actors
- Applicant / Student
- Staff
- Admin
- SMS Service

## Applicant / Student Use Cases
- Register / Verify Account
- Log In
- Manage Account
- Submit Scholarship Application
- Track Application Status
- Upload / Resubmit Requirements
- Upload / Review SOA
- View Payout Schedule

## Staff Use Cases
- Log In
- Manage Account
- Review Applications
- Verify Documents
- Schedule Interviews
- Record Interview Results
- Upload / Review SOA
- Manage Records and Archive
- Send Notifications

## Admin Use Cases
- Log In
- Manage Account
- Manage Application Period
- Manage Users
- Schedule Payouts
- Manage Records and Archive
- Generate Reports
- Send Notifications

## External Service Use Cases
- SMS Service supports Send Notifications

## Simple Flow Summary
- Applicant registers and verifies an account
- Applicant submits a scholarship application
- Staff reviews and verifies submitted documents
- Staff schedules interviews and records results
- Applicant uploads SOA if qualified
- Admin schedules payouts
- Staff and admin manage records, archive completed records, and generate reports
